# Catatan Keuanganku - UTS Praktikum PAB 2026/2027
Studi Kasus 1: Aplikasi Pencatatan Keuangan Pribadi (Flutter + Dart).

Cara menjalankan:
1. `flutter create .`  (di dalam folder ini, untuk membuat folder android/ios; file lib/ dan pubspec.yaml tetap dipakai)
2. `flutter pub get`
3. `flutter run`   (emulator Android / HP Android)

Catatan: gambar header memakai Image.network (butuh internet); jika offline otomatis tampil warna polos.
